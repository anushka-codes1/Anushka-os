## Installation

Clone the repository:

```bash
git clone https://github.com/anushka-codes1/anushka-os.git
```

Navigate into the project:

```bash
cd anushka-os
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Build production version:

```bash
npm run build
```
